# @phaselock/typespec-core

The TypeSpec vocabulary for [PhaseLock](https://phaselock.io), a sync-first
backend with generated, typed clients that work offline.  Your model file
imports this library to declare slices, mutations, engines, and queries; the
`@phaselock/typespec-ts` emitter generates language bindings from it.

Docs and examples:
[github.com/phaselock-io/phaselock](https://github.com/phaselock-io/phaselock)
