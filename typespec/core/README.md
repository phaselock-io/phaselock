# @phaselock/typespec-core

The TypeSpec vocabulary for [PhaseLock](https://phaselock.io), an
event-sourcing sync engine.  Your model file imports this library to
declare events, commands, stores, engines, and queries; the
`@phaselock/typespec-{ts,py,go}` emitters generate language bindings
from it.

Docs and examples:
[github.com/phaselock-io/phaselock](https://github.com/phaselock-io/phaselock)
